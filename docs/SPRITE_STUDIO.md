# Canvas 素材工房

從遊戲首頁下方的「素材工房」進入，或開啟 `/kids-game/#sprite-studio`。本機開發網址：`http://127.0.0.1:5173/kids-game/#sprite-studio`。

## 使用流程

1. 選擇野餐、刷牙、送貨或單字貼紙，再選關卡和單個素材。
2. 修改構圖、原畫裝飾與局部配色，或使用組合種子生成。鎖定的部件不會被隨機替換。相同種子及鎖定部件得到相同結果。
3. 查看大圖及 64／32 px 小圖，可切換預覽底色。PNG 永遠保留透明背景。
4. 在「讓這個小素材動起來」選擇輕跳、搖擺、呼吸或靜態影格；設定 4／8／12 格、2–24 FPS，以及每列最多 1／2／4／8 格。播放、暫停、前後逐格及時間軸可檢查循環。
5. 下載 Sprite 素材包，內有透明圖集 PNG、影格 JSON、可重新編輯的設計 JSON 與說明。也能分別下載 PNG／JSON，或保留原本的單張 64、128、256、512 px PNG。
6. 檢查滿意後按「標記完成」，再按「下一個未完成」。同一「遊戲／關卡／素材」只保留一個完成版本；動畫設定也會保存，修改後可更新這個版本，不會新增重複紀錄。

已使用 Chrome 實際下載 PNG 與 JSON，確認 PNG 尺寸、alpha 通道與設計參數。Codex 內嵌預覽沒有回報檔案下載；若未收到檔案，請用 Chrome 開啟同一網址下載。

完成紀錄存於目前瀏覽器的 `localStorage`（`picnic-sprite-studio-v1`）。切換素材時，本頁會保留未完成草稿；重新整理只恢復已標記完成的作品。清除瀏覽器資料會移除紀錄，重要作品請另存 JSON。無法存取儲存空間時，頁面會顯示提示。

「套用這個素材」會讓同一瀏覽器中所有遊戲的同名 `GameSprite` 使用此 Canvas 單張造型；圖集動畫需下載後由遊戲引擎播放。套用是可選的；按「恢復原有插畫」可還原，原有圖集不會被修改。這是瀏覽器內的預覽設定，不會將作品提交到原始碼或同步給其他玩家。

## 涵蓋範圍

工房提供四個遊戲主題的 **22 種**原畫合成素材，含側面／俯視車輛、人物、蛀牙蟲、牙齒、牙刷、食物、建築、植物、野餐場景與包裹。既有 246 個插畫 sprite 繼續保留；新拓展的 14 組主題圖集不是這次 Canvas 模型的範圍。聽詞揀圖共用單字素材，亦會使用同名素材的套用設定。

野餐和刷牙使用現行關卡生成器及難度分層；送貨以素材組編號對應示例路線種子；單字貼紙涵蓋目前 16 個單字素材，關卡資訊依難度顯示 4／5／6 張配對。關卡編號用來整理版本，各關原本共用相同素材。套用設定按素材名稱生效，不會改變迷宮、遊戲規則或針對某一關自動換圖。

工房在 Canvas 2D 中合成遊戲現有原畫，預設「遊戲原色／原作構圖／保留原作」會保留原圖比例、表情、陰影與水粉筆觸。調色依素材的顏色及區域遮罩作用於車身、衣服、屋頂等部分，保留明暗變化與透明通道；花朵及陽光裝飾也來自同一套圖集。所有處理在瀏覽器內完成，使用本專案同源圖片。

新版設計 JSON 使用版本 3，增加動畫設定；版本 2 設計保留原貌，補上預設動畫參數。版本 1 的幾何造型、表情與像素化設定會轉為原作插畫，保留素材、種子、尺寸、縮放、翻轉、關卡與完成紀錄；頁面會提示這項變更。現在的調整項目是構圖傾角、原畫裝飾、材質配色與輸出尺寸。

## 圖集格式

- ZIP 包含 `sprite.png`、`sprite.json`、`design.json`、`README.txt`。重新載入工房時選 `design.json`。
- 影格 JSON 採用 [Aseprite JSON hash](https://www.aseprite.org/docs/cli/#data) 的 `frames`、`meta.size`、`meta.image`、`meta.frameTags` 結構，額外提供中心 `pivot` 與 FPS。
- 所有格子保持相同尺寸，從左到右、從上到下排列；不裁掉透明邊距。未使用格子保持透明，預覽格線和編號不會匯出。
- `frame.duration` 以毫秒記錄，使用累積時間四捨五入來分配每格長度，避免非整除 FPS 的時間漂移。播放器可使用各格時間，或依 `meta.fps` 設定等速循環。
- 動作是整張原畫的位移、旋轉或縮放；目前沒有四／八方向新視角、骨架走路動作、AI 文字生成或 PixelLab API 連線。這是使用者指定先完成的 sprite sheet 階段，文字生成為下一階段。

## 維護

- `src/studio/catalog.ts`：22 種模型與四個遊戲的素材清單。
- `src/studio/draw.ts`：同源圖集載入、框位裁切、Canvas 合成、透明安全邊距、縮放與翻轉；快取有數量上限，非同步繪製只保留最新請求。
- `src/studio/materials.ts`：各素材的調色區域與色相遮罩，保留原畫紋理、輪廓和角色膚色。
- `src/studio/recipe.ts`：穩定種子、鎖定邏輯、參數驗證、版本 3 JSON 與版本 1／2 遷移。
- `src/studio/animation.ts`、`sheet.ts`、`SpriteSheet.vue`：循環動作、固定框位圖集、動畫預覽及匯出。
- `src/studio/download.ts`：PNG 編碼、檔案下載與無額外依賴的 ZIP 打包。
- `src/studio/store.ts`：完成紀錄及可還原的瀏覽器套用設定。
- `src/studio/SpriteStudio.vue`：工房介面，首頁透過 hash 路由載入。

新增素材時，把已登錄圖集框位的名稱及用途加入 catalog，在 materials 指定主要材質的色相及區域，最後加入對應遊戲清單。沿用同源素材，避免跨來源畫布無法匯出的問題。未來調整配方語意時，須更新 `Recipe.version` 並提供版本處理。

## 驗證

`npm test` 包含素材覆蓋、種子、鎖定、JSON 往返、不合法輸入、舊版遷移、完成紀錄、圖集座標／時間與 ZIP 完整性驗證。`npm run build` 執行型別檢查與正式建置。

啟動 `npm run dev`，開啟 `/kids-game/tests/studio-browser.html` 可在真實 Canvas 上檢查 22 個模型、660 次繪製、四種輸出尺寸、透明邊界、三種構圖、翻轉、材質調色及 PNG alpha；預設輸出另外與原畫等比例繪製做逐像素比對，並檢查非同步繪製不會讓舊選擇蓋過新選擇。另檢查 264 組圖集與 2,112 個動畫影格的透明邊界、循環差異、空白格與時間，並驗證圖集 ZIP 產生。頁面同時顯示完整素材檢視表。這個測試頁不會打包進正式網站。

人工瀏覽器流程另外驗證：種子錯誤提示、鎖定部件、標記完成、重新載入、跳過已完成項目、遊戲套用與恢復，以及 390 px 手機版無水平溢出。
