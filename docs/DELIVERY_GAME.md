# 送貨員來了

依使用者提供的 `IMG_5300.HEIC` 第 92 頁「送貨員來了」介紹與規則製作。照片作為玩法參考；道路與場景是重新設計的網頁地圖，沒有將教材照片嵌入遊戲。

## 圖片規則與遊戲對照

| 圖片規則 | 網頁實作 |
| --- | --- |
| 從紅色箭嘴畫線到藍色箭嘴 | 紅色起點、藍色終點；預設按住小車沿道路描線 |
| 途中依序送貨到 1 至 3 號房子 | 上方送貨單標示下一站；尚未輪到的房子不能進入，已送過的房子可再次經過 |
| 在房子前貼包裹貼紙 | 到達後須按「貼包裹」；屋前留下包裹與勾號，不能隔空貼或重複領取 |
| 同樣路徑不能走兩次 | 已完成路段標為橙色，正向及反向都不能再走；可從另一條路再次經過同一個路口 |
| 完成送貨後到終點 | 三張包裹貼紙全部完成，抵達藍色終點才成功 |

送貨目前是一張完整挑戰地圖，不計時、不扣分。貼紙只記錄本次遊玩，重玩或重新載入會清除，並非持久收藏冊。

## 操作

- 描線：從小車位置開始，沿白色道路拖曳。小車與橙色線跟隨手的位置，不會自動走完整段。放手或中斷手勢可停下，從同一位置續畫。
- 偏離道路：小車停在最後有效位置，回到小車旁再繼續，不能離開道路後從遠處切入跳過路段。
- 點選：切換為點選路口後，按箭嘴或方向鍵選擇相鄰路口。路口按鈕及包裹按鈕可使用鍵盤。
- 切換操作：清除尚未完成的一段描線，回到最近路口；保留已完成路段與已送包裹。
- 提示：在路口搜尋仍可完成的路線，只顯示下一步；若已無解則邀請重新規劃。畫到一半時先提示完成當前路段。
- 家長提示：說明卡提供找起終點、記住送貨次序與規劃回程的提問。沒有時間壓力或能力評分。

## 可重用的部分

- `src/game/routeMission.ts`：依序經過任務站、到站確認、無向路段不可重用、完成判定、提示搜尋。任務站由資料定義，沒有固定三站或包裹圖像依賴。
- `src/game/trace.ts`：道路投影、持續前進、偏離後回復位置的純函式。
- `src/composables/useRouteTrace.ts`：滑鼠、觸控與筆的 Pointer Events 描線；使用 pointer capture，手勢中斷時保留進度。
- `src/delivery/mission.ts`：送貨地圖、三間屋與順序。現在使用直線路段；曲線與任意自由畫線尚未提供。
- `src/art/sprites.ts`、`GameSprite.vue`：共用圖片登記及裁切。新增四款透明插畫：`truck`、`truck-top`、`parcel`、`courier`。

既有野餐與刷牙繼續使用原有規則及操作，避免將新送貨狀態混進漢堡任務。

## 驗證

`npm test` 涵蓋送貨全流程、順序、貼紙、逆行、重經路口、提早到終點、走入盡頭、無解提示，以及描線進度與偏離回復。`npm run build` 檢查型別並產生正式靜態網站。

瀏覽器另外驗證桌面與 390px 手機版：半段停手續畫、偏離提醒、到站貼包裹、切換操作、阻止跳站，以及全程以方向鍵與 Enter 完成三站送貨並抵達終點。檢查時沒有瀏覽器錯誤或警告。
