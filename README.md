# 小小出遊家

**現在就玩：** https://game1.iclover.net/kids-game/

本機專案內含三款小路遊戲與一款圖詞配對；迷宮同一路段僅可通行一次。新增遊戲須部署後才會出現於線上版本。

- **一起去野餐**：先到漢堡店，再前往公園。
- **打敗蛀牙蟲**：走到終點，途中不可遇到蛀牙蟲。
- **送貨員來了**：從紅色起點畫線，依序到 1、2、3 號屋，再到藍色終點。
- **貼紙學單字**：拖貼紙配英文詞，全部放對就過關。不計時、不扣分；不是貼紙冊。
- **聽一聽揀圖**：聽到粵語詞之後，點啱嘅圖。不計時、不扣分。

## 項目核心理念

以有趣、循序漸進的迷宮活動，讓孩子在親子陪伴下練習觀察、選擇與主動操作。設計聚焦精細動作、認知練習、手眼協調與空間方向，以及親子共玩的樂趣。

野餐與刷牙以點選選路為主；送貨遊戲已加入沿路描線、屋前包裹貼紙與家長提示。紙筆延伸及持久貼紙收藏仍為後續方向。完整理念、三階段設計與現況說明見 [項目核心理念與設計準則](docs/PRODUCT_PRINCIPLES.md)。

## 開始玩
電腦：用瀏覽器開啟 [線上版本](https://game1.iclover.net/kids-game/)，或依下方「本機開發」啟動預覽，選擇遊戲後按「開始遊戲」。
手機／平板：建議用 Safari／Chrome 開啟上述網址。部分聊天軟件或檔案預覽不會執行 HTML 入面嘅 JavaScript。

## 玩法
點一下發光圓圈，小車會自動沿小路行到下一個路口。
亦可以由小車向相鄰光圈輕掃；電腦可用方向鍵。
必須先到漢堡店，再到公園。走過嘅路會變橙色，同一段路不能再行，包括反方向。
行到盡頭或未買漢堡就到公園，會有溫柔提示，可以重新出發。冇計時、冇扣分。
「提一提」會找出仍可完成任務嘅路線，將下一步變成綠色光圈；已無解時提供重新出發選項。

## 送貨玩法

按住藍色小車，沿白色道路畫線；小車跟隨操作前進，未到路口前可拉回改選方向。放手可停下並從原位續畫。偏離道路時回到小車旁再繼續。到達房子便完成該站。先送 1、2、3 號屋，再到藍色終點。可以重經路口，但不能重走路段，包括反方向。

亦可切換「點選路口」，使用箭嘴或方向鍵。切換方式會回到最近完成的路口，保留已完成路段和送貨記錄，未畫完的一段會清除。「？」內有規則及家長引導。完整對照與共用模組見 [送貨遊戲說明](docs/DELIVERY_GAME.md)。

## 野餐關卡
每次進入野餐、刷牙或送貨，都會隨機出新的小路。同一局重玩本關地圖不變；返回選單再開才換新圖。野餐與刷牙過關後可再玩下一張。
右上角「？」可查看遊戲說明。

## 網站部署
已用 GitHub Pages 公開於 https://game1.iclover.net/kids-game/ （`skyhilam.github.io/kids-game` 會轉去呢度）。
執行 `npm run build` 後，發佈完整 `dist/` 目錄（包含圖片與程式素材）。網站執行時不需要後端或資料庫。
本機檢查正式版本：

    npm run build
    npm run preview

然後開啟終端顯示的預覽網址。

## 聲音、私隱與離線
程式與插畫素材隨網站一同提供，不依賴第三方圖庫，沒有廣告、追蹤器或登入。首次載入需要網路；沒有提供離線重新載入保證。
不保存個人資料，重新載入會回到遊戲選單。
野餐、刷牙與送貨的移動／勝利／失敗音效可用右上角喇叭關閉；關閉後音效與旁白一併停止。貼紙學單字放對時用裝置英文語音讀該詞，不會用粵語讀英文。
聽一聽揀圖用粵語讀目標詞；裝置冇廣東話語音時保持安靜，不會改用普通話或英文朗讀粵語詞。
粵語旁白使用瀏覽器提供嘅廣東話語音；裝置冇該語音時，自動保留圖示、文字同音效，不會改用普通話朗讀粵語。
裝置語音能否離線運作，視乎裝置有冇下載對應語音。

## 技術

### Canvas 素材工房

首頁下方的「素材工房」可按遊戲／關卡製作目前使用的 22 種單個素材。沿用遊戲原畫的繪本風格，支援構圖、局部調色、原畫裝飾、可重現種子與鎖定。可製作 4／8／12 格循環動畫，逐格預覽並匯出 sprite sheet PNG、影格 JSON 及整包 ZIP；動畫設定會隨完成紀錄保存。單張造型仍可下載或套用到遊戲，並隨時恢復原畫。

執行 `npm run dev` 後開啟 `/kids-game/#sprite-studio`。操作、範圍與維護方式見 [Canvas 素材工房](docs/SPRITE_STUDIO.md)。

Vue 3 + TypeScript + Vite。各款遊戲共用透明插畫素材庫，由 `src/art/sprites.ts` 登記，透過 `GameSprite.vue` 使用。新增遊戲可直接重用角色、場景和道具，詳見 [共用素材使用說明](src/art/README.md)；參考照片的逐張處理狀態見 [處理紀錄](src/art/reference-progress.json)。箭頭、音量等介面符號保留為可變色的 SVG。
支援觸控、滑鼠、方向鍵，響應式手機／平板版面及減少動態效果設定。
野餐與刷牙共用無向迷宮規則（`src/game/`）；關卡與文案分屬 `src/picnic/` 與 `src/tooth/`。送貨為獨立路線任務。可用 `npm test` 驗證。
公開 repo 嘅 `main` 已禁止 force-push／刪除分支，Wiki 關閉。

本機開發：

    npm install
    npm test
    npm run dev

正式檔由 GitHub Actions 建置並發佈到 GitHub Pages。
