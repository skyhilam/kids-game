# 小車：揮手、眨眼與車輪動作

這是一張 8 格透明動作原畫圖集，每格改變手臂姿勢、眼睛及輪轂。參考 `../sprites.png` 第一排第二格的小熊小車，沿用繪本筆觸與角色外觀。原有靜態圖集沒有被覆蓋。

使用內建 **imagegen** 生成；未使用 CLI、外部生成 API 或 Python 修改圖片像素。最終 PNG 原樣複製到本目錄。Canvas 按框位裁切，依車身位置對齊及縮放，並沿用工房的局部調色、翻轉和裝飾。

## 提示詞與修正

1. [初始提示詞](prompt.txt)：建立揮手、眨眼及車輪轉動的 8 格圖集。
2. [第一輪修正](correction-prompt.txt)：修正第三格錯用另一隻手，保留透明安全邊距。
3. [第二輪修正](pose-prompt.txt)：加大第 6–8 格的手臂動作，讓揮手清楚可見。

## 處理狀態

[manifest.json](manifest.json) 記錄處理狀態、來源及輸出 SHA-256、框位和各格車身定位。完成前須檢查手部姿勢、眨眼、透明邊界、動作播放及匯出，不因圖片檔案已存在就視為完成。

每次只製作一個素材的動作圖集。這次完成的是側面小車 `car`；其他素材使用工房的一鍵生成流程，尚未生成時標示為待生成。

這是逐格原畫動畫，並非骨架動畫或任意提示詞動畫生成器。生成影格的筆觸仍有細微差異；Canvas 以車身邊界對齊，減少整張圖片跳位。
